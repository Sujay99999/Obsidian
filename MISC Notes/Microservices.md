When is it called a Microservice
	Each component must be a part of the "No shared framework", where the component must not share any database with another
	Each component talsk to another with proper API interfaces or async messages
	Each component must be deployed onto a seperate Runtime process

Microservice is basically an Architectural style, of decomposing the Monolithic component into smaller autonomous components, which can be scaled independently
